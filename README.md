# ☕ Java Fundamentos

Bem-vindo ao meu repositório de estudos de **Java**

Este espaço foi criado para documentar minha evolução na linguagem Java, reunindo exercícios, desafios e projetos desenvolvidos ao longo do meu aprendizado. O objetivo é construir uma base sólida em programação orientada a objetos e desenvolvimento Back-End, registrando cada etapa da jornada.

## 🎯 Objetivo

Este repositório funciona como um portfólio de estudos, onde adiciono constantemente novos exercícios e projetos conforme avanço nos cursos e práticas de programação.

Os principais objetivos são:

* Aprimorar a lógica de programação;
* Dominar os fundamentos da linguagem Java;
* Praticar resolução de problemas;
* Desenvolver boas práticas de programação;
* Criar um histórico da minha evolução como desenvolvedora.
* Melhorar meu histórico e dominío do Git e GitHub.
