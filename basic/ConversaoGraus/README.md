# 🌡️ Conversor de Temperatura - Celsius para Fahrenheit

## 📌 Sobre o Projeto

Este projeto foi desenvolvido em **Java** com o objetivo de praticar conceitos fundamentais da linguagem, como:

* Entrada de dados com `Scanner`
* Estruturas de repetição (`do-while`)
* Variáveis e tipos primitivos
* Operações matemáticas
* Formatação de saída com `printf`
* Interação com o usuário

O programa solicita uma temperatura em **Celsius**, realiza a conversão para **Fahrenheit** e exibe o resultado na tela. Ao final, o usuário pode escolher se deseja realizar uma nova conversão.

---

## 🚀 Fórmula Utilizada

```text
F = (9 * C / 5) + 32
```

Onde:

* `C` = Temperatura em Celsius
* `F` = Temperatura em Fahrenheit

---

## 💻 Exemplo de Execução

```text
Digite a temperatura em Celsius:
25

Equivalente em Fahrenheit: 77.0

Deseja repetir (s/n)?
s

Digite a temperatura em Celsius:
30

Equivalente em Fahrenheit: 86.0

Deseja repetir (s/n)?
n
```
