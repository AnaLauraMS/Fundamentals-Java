# 🧮 Calculadora de IMC

Projeto desenvolvido durante meus estudos de Java.

## 📚 Objetivo

Praticar os conceitos básicos da linguagem Java:

- Entrada de dados com Scanner
- Variáveis
- Operadores matemáticos
- Estruturas condicionais (`if` / `else`)
- Saída formatada (`printf`)

## 🚀 Funcionalidades

- Informar peso
- Informar altura
- Calcular IMC
- Exibir classificação

## 💻 Tecnologias

- Java
- IntelliJ IDEA

## 📷 Exemplo

```text
CALCULADORA DE IMC

Informe seu peso:
70

Informe sua altura:
1.75

Seu IMC é: 22.86

Peso normal
