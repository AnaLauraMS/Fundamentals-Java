# 🎯 Jogo de Adivinhação em Java

Um projeto simples desenvolvido em **Java** para praticar conceitos fundamentais da linguagem, como entrada de dados, estruturas condicionais e laços de repetição.

## 📌 Sobre o projeto

O programa possui um número secreto definido como `7`. O usuário deve tentar adivinhar esse número, informando valores entre **0 e 10**.

A cada tentativa, o programa fornece uma dica:

* ⬆️ Se o número informado for menor que o número secreto, solicita um número maior.
* ⬇️ Se o número informado for maior que o número secreto, solicita um número menor.
* 🎉 Quando o usuário acerta, o programa exibe uma mensagem de parabéns e encerra.

## 🧠 Conceitos praticados

Este projeto foi desenvolvido para praticar:

* Variáveis e tipos primitivos
* Entrada de dados com `Scanner`
* Estrutura condicional `if / else if / else`
* Estrutura de repetição `while`
* Operadores relacionais
* Comparação de valores
* Controle de fluxo
* Fechamento do `Scanner`

## 💻 Exemplo de execução

```text
Digite um número de 0 a 10: 3
Tente um número maior.

Digite um número de 0 a 10: 9
Tente um número menor.

Digite um número de 0 a 10: 7
Parabéns! Você acertou!
```

* **Java**

1. Clone este repositório:
